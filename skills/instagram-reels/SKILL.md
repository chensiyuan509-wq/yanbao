# Instagram 竖版导出

用户的视频是横版的电影感讲解片（常带 2.2:1 遮幅和烧录字幕），Instagram 需要竖版。本技能只负责**导出文件**；
发帖由用户在手机上自己完成（Instagram 没有给个人账号的上传接口）。

## 用法

用带 pycairo 和 imageio-ffmpeg 的 python（例如视频项目的 venv）运行：
```bash
S=~/.claude/skills/instagram-reels/scripts/export_instagram.py
python $S out/片名_1080p.mp4 --start 101 --end 160 --title "勾股定理的拼图证明"   # 一段
python $S out/片名_1080p.mp4 --chapter 3                                        # 一章（在视频项目目录里）
python $S out/片名_1080p.mp4 --all-chapters                                     # 每章一条
python $S out/片名_1080p.mp4 --format feed --start 30 --end 75                  # 动态 4:5
```
输出在源视频旁的 `instagram/` 里：`.mp4`、`_cover.jpg`（封面）、`.txt`（配文草稿）。
源视频没有遮幅黑边时加 `--no-letterbox`（否则模糊底会多裁一截）。

## 怎么切才好看

- **源用 1080p**：480p 竖放后明显发糊（脚本会提醒）。
- **时长**：Reels 目前上限约 3 分钟（以 Instagram 最新规定为准），30–90 秒的完播率最好。
  长片按"一个完整的小故事"切：一个证明、一个实验、一件发明、一个人物，而不是机械地按章节对半切。
- **开头 2 秒要抓人**：起点选在一个有冲击力的画面（壁画推近、强光、照片快门），而不是安静的章节字卡；
  标题条替代字卡告诉观众这段讲什么。
- **安全区**：Instagram 界面会盖住顶部约 250 像素、底部约 350 像素和右侧一列按钮。
  标题条在 y≈330–630，横版画面在正中，都避开了；不要另加东西到底部。
- **封面**：选画面最强的一帧（`--cover 秒数`）；主页网格只显示中间部分，主体要在中央。
- **系列感**：同一部片切出的多条，标题统一格式（如"星火 03｜勾股定理的拼图证明"），封面取同一类画面。

## 配文与署名

`.txt` 是草稿：标题 → 一两句亮点 → "历史图像来自 Wikimedia Commons（公有领域 / CC0 / CC BY），出处见画面左下角" →
完整版链接（YouTube 发布后再填）→ 话题标签。用到 CC BY 图片的片段，配文里写上作者和授权
（片中出处字幕里有；也可以参考 youtube-publish 生成的简介里的 CC BY 列表）。

## 传到手机

文件在电脑上、发帖在手机上：小于约 19 MB 的可以用 **gmail-send** 发到邮箱；更大的先压缩，或用其他方式传。
