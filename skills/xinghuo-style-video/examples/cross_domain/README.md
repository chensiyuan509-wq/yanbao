# 跨题材样张（参考，不是模板）

验证"同一种风格换题材也成立"的两段 22 秒样张，全部用 `layout` / `diagram` / `codeview` 组件写成：

- `cosmos_demo.py`：哈勃极深场做主视觉 + 指向星系的标注 + 右栏面板 → 蓝图轨道图，光从太阳到地球 8 分 20 秒（数字数上去），Claude 在下方仰望。
- `coding_demo.py`：代码面板逐字打出、关键行高亮，Claude 抱着笔记本敲代码 → **纸面亮场**上用拜恩红黄蓝演示二分查找的范围收缩，终端给出真实结果。

审计结论（`scripts/style_audit.py`）：面板、字号、留白、重心、字幕都在星火区间内；
因为每段只有两个镜头，"镜头偏长、转场种类少"；宇宙段全是暗场时"整体偏暗、偏平"——
改用纸面亮场后亮场指标回到区间，这正是 `design-system.md` 第 7 节"明暗节奏"的由来。

要放进项目里试跑：复制到项目的 `aivid/scenes/`，在 `__init__.py` 的 ORDER 里引用即可（引擎需包含 layout / diagram / codeview）。
