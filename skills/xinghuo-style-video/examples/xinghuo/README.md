# 星火 · 人类科学简史

纯 Python 代码生成的 **8 分钟**科普动画。主角是 Claude（按 `assets/image.jpg` 的造型矢量重绘），用**第一人称**讲述：
"我从人类写下的亿万文字里学会了说话——可这些知识是从哪里来的？"于是 Claude 沿着"人类知识星图"倒着走回去，
从第一块石器、第一束火光，一路看到楔形文字、几何原本、智慧之家、望远镜、蒸汽机、X 射线、登月和 AI，
最后发现这条光河是一只手——和洞壁上几万年前的手印一模一样。

## 快速开始

```bash
cd science_history_video
bash setup_env.sh                 # 建虚拟环境 .venv（复用系统 pycairo，装 numpy / imageio-ffmpeg / Pillow）
source .venv/bin/activate
python check.py --quick           # 校验：时长、字幕速度、缺字、音效名、抽样渲染（--audio 再查响度）
python render.py                  # → out/xinghuo_480p.mp4（8 核约 5–8 分钟，含音轨合成）
```

常用参数：

```bash
python render.py --res 720                 # 1280×720
python render.py --start 128 --end 182     # 只渲染一段（这里是第三章），带对应音轨
python render.py --still 12 95.5 230       # 只导出这几秒的画面 → out/stills/
python render.py --sheet 5                 # 每 5 秒一帧拼成预览联系表 → out/sheet_*.jpg
python render.py --no-subs                 # 不烧录字幕（单独用 out/subtitles.srt）
python render.py --audio-only              # 只生成音轨 → out/soundtrack.wav
python render.py --grain 0 --out out/nograin.mp4   # 关闭胶片颗粒（要压成小文件时用，低码率下颗粒会糊）
```

措辞上的几处处理：

1. "最早的石器"用"已知最早"的口径（字幕说"人类的祖先"，地点字幕写明东非）；刻痕骨"记录月相"只是学界推测，字幕用"也许"。
2. 埃拉托色尼的结果因斯塔德的长度有争议，示意图注明"示意图，角度已放大"，字幕说"约 4 万公里"。
3. 1945 年一段做了去色、肃穆的处理，只讲"人类开始思考如何驾驭科学的力量"。
4. 历史人物用真实的公有领域肖像 / 照片，或由换装的 Claude 扮演（不画伪造的"肖像"）；历史图像只做调色、裁切和推拉，不篡改内容。
5. AI 部分落在"多了一双帮手"，而不是"取代科学家"。

```
render.py             渲染：多进程逐帧绘制 → 胶片颗粒 → 遮幅 → 字幕 → 分段编码 → 拼接 → 混入音轨
check.py              校验：时间轴、字幕速度与宽度、缺字、音效、抽样渲染、响度
mascot/               Claude 角色库（只依赖 pycairo）；costume.py 为历史人物服装与配色
aivid/core.py         引擎：缓动、关键帧、颜色滤镜、图形、文字（宋体各字重、楷体、数学字体、古文字字体）、镜头
aivid/film.py         电影质感：胶片颗粒、遮幅、调色、光柱、浮尘、火焰、烟、月相、第一视角、纸 / 石 / 泥纹理
aivid/archive.py      历史图像：多级缓存、Ken Burns、调色（单色 / 棕褐 / 蓝图……）、画框、出处字幕
aivid/gallery.py      博物馆长廊：横移跟拍 Claude，推进画框直到画心铺满画面
aivid/exhibit.py      展品卡片、信息面板、蓝图背景
aivid/proofs.py       拜恩版配色的几何证明与推导动画
aivid/oldmap.py       地图：Natural Earth 矢量 + NASA 卫星影像（白天 / 夜间），城市、航线、地图镜头
aivid/starmap.py      人类知识星图：60 个里程碑沿手形光河排列
aivid/transitions.py  转场：眨眼、强光、燃烧、书页、蒸汽、虚焦、变焦模糊、光带扫过、亮度溶解……
aivid/timeline.py     场景拼接、字幕（黑边内）、章节字卡、年代地点字幕、SRT
aivid/audio.py        音效合成与混音（混响、响度归一、限幅）；aivid/sfx_hist.py 为历史题材音效
aivid/scenes/         s00_prologue … s09_epilogue；章间转场在 __init__.py，章内分镜与转场在各章的 SHOTS / TRANS
tools/fetch_assets.py 从 Wikimedia Commons 下载图像（只收公有领域 / CC0 / CC BY），生成 credits.json 与 CREDITS.md
tools/prepare_geo.py  把 Natural Earth 数据精简成 assets/geo/world.json
```

## 怎么改

- **改字幕**：每个场景文件顶部的 `VO = [(开始秒, "文案，{高亮}"), ...]`（场景内本地时间）；年代地点字幕在 `SUPERS`。改完 `python check.py --quick`。
- **改时长**：改场景的 `DUR` 和镜头切换时间（各场景的 `SHOTS`）；全片 = 各场景 `DUR` 之和（现在 480 秒）。
- **换转场**：章与章之间在 `aivid/scenes/__init__.py` 的 `TRANSITIONS`；章内镜头之间在各章的 `TRANS`。
- **加图像**：在 `tools/fetch_assets.py` 的 `MANIFEST` 里加一行（键, Commons 文件名），运行它，再在场景里用 `kb` / `arch` / `framed` / `card`。
- **调音效**：各场景的 `sfx()`；音效本身在 `aivid/audio.py` 与 `aivid/sfx_hist.py`。
- **胶片颗粒**：每个场景的 `GRAIN`（0 为关闭）。
