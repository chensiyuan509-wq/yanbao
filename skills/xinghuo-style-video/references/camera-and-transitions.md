# 运镜与转场

原则：**镜头永远在动，但动得很慢；切换像电影剪辑，不像幻灯片。** 观众感觉到的是"被带着走"，而不是"翻了一页"。

## 运镜

| 运镜 | 怎么做 | 参数习惯 |
|---|---|---|
| Ken Burns 推拉 | `kb(ctx, key, t, t0, t1, c0, c1)`，c = (中心 u, 中心 v, 缩放) | 一个镜头内缩放 1.0 → 1.25–1.5；往故事重点推（"右下角拿圆规的人"） |
| 推近细节 | 同上，最后一段推到 2–2.4 倍，配一个标签点名 | 雅典学院推到欧几里得：`(0.5,0.5,1.02) → (0.76,0.76,2.4)` |
| 展厅横移跟拍 | `Gallery(items, actor, t0, t1, push=i, lead=…)` | 横移速度 400–600 px/s（设计坐标）；前 2 秒可以停在空墙给章节字卡留位置 |
| 推进画框 | Gallery 最后 `push_dur` 秒自动推到画心铺满（1.02 倍），画框中心移到画面正中 | 接一个**硬切**到同图 `kb(…, (0.5,0.5,1.02), …)`，无缝"走进画里" |
| 地图飞行 | `oldmap.MapCam([(t, (lon, lat, k)), …])`，`ease_io` | k≈20–26 看一个地区，9–13 看一条丝路，7 看全球；夜景 k ≥ 6.5（再小两极外露黑边） |
| 卡片慢推 | 整组 `ctx.scale(1 → 1.04)` | 静态排版也要有呼吸感 |
| 第一视角 | `pov_arm` 伸手、`eyelids` 睁眼、手持轻微晃动 `sin(t*1.2)*6` | 用在"我"亲手做事的瞬间：打石、压泥板、看望远镜、触碰星座 |
| 记忆漂浮 | 缩略图在 z 方向循环漂近，透明度随深度变化 | 序章 / 回望段 |

缓动统一用 `ease_io`（推拉、飞行）和 `ease_out`（入场）。元素入场一律"淡入 + 上浮"或"由虚到实"，不弹跳。

## 转场

两层：**章与章之间**（`aivid/scenes/__init__.py` 的 `TRANSITIONS`，1.0–1.8 秒）和**章内镜头之间**（各章 `SHOTS` + `TRANS`，0.6–1.2 秒，用 `sequence()`）。

### 章间转场（有"仪式感"，配音效）

| 种类 | 画面 | 适合 | 示例参数 |
|---|---|---|---|
| `blink` | 第一视角眼睑合上再睁开 | 序章 → 第一章；回望 → 尾声 | `("blink", 1.3, {"sound": "hush", "gain": 0.3})` |
| `flare` | 强光过曝（日出、火光） | 太阳 / 光的意象收尾 | `{"x": 960, "y": 540, "sound": "swell"}` |
| `lightsweep` | 一道光带斜扫，光后是新画面 | 时代切换、通用 | `{"color": "#FFE2B0", "angle": 0.35}` |
| `burn` | 纸面被烧穿露出下一章 | 图书馆被毁 → 下一个文明 | `{"seed": 11, "sound": "ignite"}` |
| `pages` | 一阵书页飞过遮挡 | 印刷 / 书籍 → 下一章 | `{"seed": 5, "sound": "pages_flurry"}` |
| `smoke` | 蒸汽涌过 | → 蒸汽时代 | `{"seed": 3, "sound": "steam"}` |
| `flash` | 电光闪白 | → 电、爆炸、X 射线 | `{"sound": "crackle"}` |
| `defocus` | 虚焦再对焦 | 时间流逝、回忆 | `{"max": 16, "sound": "hush"}` |
| `match` | 两个圆形物体重合溶接 | 形状呼应（轮盘 → 圆） | `{"a": (x,y), "b": (x,y), "ra": r, "rb": r}`，**必须两边真的有同位置的圆** |

### 章内转场（轻、快，0.6–1.2 秒）

| 种类 | 适合 |
|---|---|
| `dissolve`（可带 `zoom`） | 默认；两张历史图之间 |
| `luma` | 照片 → 示意图 / 蓝图（亮处先浮现，像显影） |
| `lightsweep` | 换话题、换时代；可调 `angle` 和 `color`（科技段用 `#BFE0FF`） |
| `zoomblur` | "冲进去看"：卡片 → 曲线、发射、深入细节；`x, y` 设在要冲进去的物体上 |
| `defocus` | 场景换气、回到抽象 |
| `flare` | 光源 → 下一镜（太阳、聚变核心） |
| `flash` | 爆炸、放电（短，0.5–0.6） |
| `dip` | 肃穆的段落之间（1945 → DNA），黑场一下 |
| 硬切（不写进 TRANS） | 推进画框后接画内镜头；需要节奏感的连续实物 |

规则：
- 相邻两个转场不用同一种；一章里至少 3 种。
- 转场位置要有"理由"：光 → 用 flare；纸 → burn / pages；电 → flash；冲进细节 → zoomblur。
- `sequence()` 在转场窗口里**两个镜头都会用同一个 t 渲染**，所以镜头函数要能处理 t 略早于 / 晚于自己区间的情况（用 `prog` / `clamp` / `kb` 天然安全；别用 `int(u/…)` 这种负数会出错的写法当索引）。
- 章间转场的音效写在参数 `sound` / `gain` 里，章内转场的音效写在本章 `sfx()` 里。

## 节奏

- 一个镜头 3–6 秒；纯画面（无面板）的"呼吸镜头"2–3 秒，用在大事件前后（发射、黑洞、地出）。
- 一章 50–70 秒 ≈ 8–14 个镜头。开头 4 秒留给章节字卡（画面要安静、留出位置）。
- 重要瞬间的处理：先 0.5–1 秒安静（hush / 暗场）→ 再揭晓（boom / 强光 / 照片快门）。
