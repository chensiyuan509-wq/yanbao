# 设计系统：分镜、信息分层、版面与每一帧的美学

这份文档是风格一致的核心。它从《星火》全部场景代码（83 个镜头、125 句字幕、约 260 个音效）和成片 480 帧的
画面统计里归纳出来，写成**与题材无关**的规则：做科学史、宇宙、编程、人物、产品……都按它来，片子看起来就是同一个"作者"。
具体数值是"星火实测 → 目标区间"，区间之内自由发挥。

## 1. 五条设计原则

1. **一镜一事**：每个镜头只讲一个点；画面的主角只有一个（一张图、一个机制、一个数字）。
2. **真实打底，图解点睛**：主视觉优先是真实的东西（文物、照片、天文影像、真实代码与终端输出）；
   图解（蓝图、纸面、数据）用来讲"怎么做到 / 为什么"，和真实画面交替出现。
3. **先看见，再读到**：画面先出现、先动起来，文字随后逐条浮现；观众的眼睛永远先落在主视觉上。
4. **克制的强调**：全片只有一种强调色（金 `#FFD27A` / `#D9B26A`），纸面图解里换成拜恩红黄蓝；每屏强调 ≤ 2 处。
5. **一直在呼吸**：画面不会静止超过 2 秒（缓慢推拉、光点流动、粒子），但也绝不抢戏（不弹跳、不旋转飞入）。

## 2. 版面网格（设计坐标 1920×1080，组件里的 `GRID`）

```
y=0    ┌──────────────────────────── 遮幅黑边 96 ─────────────────────────────┐
y=96   │ [年代/地点 SUPERS  x=118 y=160]                                         │
       │            镜头标题 h1（y≈170，主视觉上方或居中）                          │
y=180  │  ┌───────────── 主视觉区 hero ──────────────┐   ┌── 右栏 info ──────┐  │
       │  │  x 118 – 1180                               │   │ x 1180–1820      │  │
       │  │  真实图像 / 机制图 / 代码面板 / 地图        │   │ 面板：标题+3–4行 │  │
       │  │  重心在画面中线附近（实测 0.50）            │   │ + 结论           │  │
       │  │                                             │   └──────────────────┘  │
       │  │                                             │   （下半右栏：第二个  │
       │  │                                             │     小组件，如终端）   │
y=840  │  └─────────────────────────────────────────────┘                        │
y=900  │ [出处字幕 caption x=118]                 Claude 站位：脚底 y≈905–960     │
y=984  ├──────────────────── 遮幅黑边：字幕在这里 ─────────────────────────────┤
y=1080 └───────────────────────────────────────────────────────────────────────┘
```

- 星火实测：信息面板 17 个，左上角 x 集中在 1150–1400，顶 y 集中在 160–220，宽 540–640。
- 文字的横向分布两个峰：右栏（x 1200–1600，占大多数）和左侧主视觉内的标注（x 400–600）。
- 左右不对称、但亮度重心居中：主视觉偏左而亮，面板在右而暗，整体平衡（指纹 `luma_center_x` 0.50）。
- 需要全屏的主视觉（油画全景、深空、地图）时，面板可以收掉或缩成右上的小卡片；需要左右对比时可以左图右文（左 58%）。

## 3. 信息分层（L0–L5）

| 层 | 内容 | 字体 / 字号 / 颜色 | 位置 | 数量 |
|---|---|---|---|---|
| **L0 主视觉** | 真实图像、机制图、代码、地图、角色表演 | — | hero 区或全屏 | 每镜 1 个 |
| **L1 镜头标题** | 这一镜讲什么（"1905 · 奇迹年""在 16 个数里找 47"） | 宋体 Black 34–44，暖白 / 金 | 主视觉上方 y≈170 或面板顶 | 0–1 |
| **L2 面板标题** | 面板的主题（"哈勃极深场 · 2004"） | 宋体 SemiBold 30，金 `#D9B26A` | 面板顶 | 每面板 1 |
| **L3 要点 / 数值** | 3–4 行要点；"说明 ……… 数值"对齐；最后一行结论 | 正文 26–30 暖白；数值 34 Black 金；结论金或橘红 | 面板内 | ≤ 4 行 + 1 结论 |
| **L4 标注** | 指向画面细节的说明（"右下角拿圆规的人"） | 28 SemiBold + 投影；副行 22 | 贴近细节，引线 | 每镜 ≤ 2 |
| **L5 出处 / 注释** | 作品 · 年代 · 作者 · 授权；"示意图，比例已夸大" | 标题 36 + 小字 20–22，`#9A8C78` | 左下 x=118 | 每张真实图 1 |
| 字幕（L3 的口播替身） | 一句一个事实 | 黑体 Medium 46，高亮金 | 下黑边 | 每 3–5 秒一句 |

规则：
- 同一屏最多出现三个层级的文字（例如 L1 + L3 + L5），再多就拆镜头。
- 字号阶梯固定：118 / 40 / 34 / 30 / 28 / 24 / 20。不要发明 31、33 这种中间值。
- 字幕说的和面板写的**互补而不重复**：字幕讲结论或故事，面板给数据和步骤。

## 4. 图层顺序（从下到上）

背景底（渐变 / 纹理 / 蓝图网格 / 纸面）→ 主视觉（真实图像的 Ken Burns、机制动画）→ 调色与暗角 →
主视觉上的叠加（光点、引线标注、轨道）→ Claude（`lit()` 染场景光）→ 信息面板 → 出处字幕 →
（全片统一由引擎画）胶片颗粒 → 遮幅黑边 → 字幕 / 章节字卡 / 年代字幕。
面板永远在 Claude 之上；Claude 永远在主视觉之上；字卡出现的 4 秒里，镜头内的面板和标注都不要出现。

## 5. 出场编排（一个 4–6 秒镜头的时间线）

| 时间（相对镜头开始） | 发生什么 |
|---|---|
| 0 | 主视觉已在（转场把它带进来），缓慢推拉开始 |
| 0.2–0.6 s | 出处字幕淡入（真实图像镜头） |
| 0.4–0.8 s | 面板淡入 + 上浮 16 px；L1 标题同时或稍早 |
| +0.3 s 起每 0.3–0.5 s | 面板要点逐条浮现，和字幕说到它的时刻对齐 |
| 60–75% 处 | 结论行 / 高亮数值出现；标注引线指向细节 |
| 最后 0.5 s | 出处字幕淡出，其余留到转场里一起被带走 |

不出现的东西：弹跳、旋转、逐字飞入、闪烁强调（除了光标）。数字可以"数上去"（`stat(count_from=…)`），只用在关键数字。

## 6. 信息密度预算

| 粒度 | 星火实测 | 目标 |
|---|---|---|
| 镜头时长 | 中位 4.6 s（10% 2.8 s，90% 9 s） | 3–7 s；超过 8 s 必须有明显的镜头内运动或两段式 |
| 字幕 | 每分钟 15.6 句，中位 23 字，7 字/秒 | 每分钟 12–18 句，≤ 8 字/秒，单句 ≤ 32 字 |
| 数字 | 53% 的字幕带数字，每分钟 12.5 个数字 | 知识类片子 ≥ 40% |
| 高亮 | 72% 的字幕有一个 `{高亮}` | 每句最多 1 个 |
| 面板 | 3–4 行 + 结论 | 每屏 ≤ 1 个面板（右下可再有一个小组件） |
| 真实图像 | 8 分钟 57 张不同的图 | 每分钟 ≥ 5 张真实视觉（编程题材：真实代码 / 终端 / 硬件照片也算） |
| Claude | 每章 ≥ 1 次（13 个参观者 + 13 个扮演角色 + 多处第一视角） | 每段 ≥ 1 次 |
| 音效 | 每分钟约 32 个触发点，环境底占 28% | 环境底不间断；动作音对齐画面 |

一段 60 秒大约：8–14 个镜头、12–16 句字幕、8–12 个真实视觉、2–4 个机制动画、10–20 个具体数字。

## 7. 每一帧的美学：画面指纹（`scripts/style_audit.py` 自动测）

| 指标 | 星火实测（中位，10%–90%） | 目标区间 | 含义 |
|---|---|---|---|
| 画面亮度 | 0.23（0.07–0.64） | 0.14–0.36 | 暗调、电影感；但不是一直暗 |
| 亮场亮度（90% 分位） | 0.64 | 0.45–0.85 | 必须有明亮的画面（纸面、油画、照片） |
| 明暗对比（p95−p5） | 0.47（0.13–0.76） | 0.30–0.68 | 主体亮、背景暗，有层次 |
| 饱和度 | 0.39（0.17–0.68） | 0.22–0.56 | 保留真实图像原色，不额外加艳 |
| 留白（平静区块占比） | 0.64（0.05–0.89） | 0.45–0.92 | 大约 2/3 是安静区域，细节集中在主体 |
| 细节密度 | 0.062（0.016–0.26） | 0.02–0.12 | 质感来自主视觉，不来自堆元素 |
| 亮度重心 x | 0.50（0.44–0.53） | 0.42–0.58 | 左右平衡 |
| 冷暖 | 暖色中位 0.99，冷场 10% 分位 0.03 | 两极分布 | 人文 / 历史段落暖，原理 / 科技段落冷（蓝图），不混成中间色 |

两条从指纹里读出来的规律：
- **明暗节奏**：亮场（油画、纸面图解、照片）和暗场（蓝图、星空、代码、夜景）交替；不要连续三个镜头都是深色底。
  每 30–60 秒至少一个亮场。编程、宇宙题材天然偏暗，要**主动**安排亮场（纸面算法图、真实照片、白天的地球）。
- **冷暖分区**：一个镜头要么是暖的（历史、人、火光、纸），要么是冷的（机制、数据、宇宙），强调色始终是金色。

## 8. 镜头语法：12 种抽象镜头

| 镜头 | 作用 | 构图与时长 | 历史（星火） | 宇宙 | 编程 |
|---|---|---|---|---|---|
| **定场 Establish** | 交代时代 / 场域，给情绪 | 全屏主视觉慢推，3–5 s，可无面板 | 《夜色中的煤溪谷》 | 哈勃深场、地出 | 机房照片、ENIAC、深夜的城市灯光 |
| **实物 Artifact** | 让观众看清"真东西" | 主视觉 + 出处 + 右栏 3 行要点，4–6 s | X 光片、日食底片、阿达手稿 | 望远镜照片、探测器、陨石 | 真实代码面板逐字打出、真机照片 |
| **人物 Person** | 谁做的 | 左图右文 / 暗墙画框，4–5 s | 爱因斯坦 1905 列表 | 哈勃、勒维特的肖像 | 图灵、霍珀的照片 |
| **机制 Mechanism** | 怎么做到的 | 蓝图 / 纸面动画 + 编号步骤，5–8 s | 蒸汽机剖面、干涉仪光路 | 轨道、引力透镜光路 | 数据流、调用栈、架构图 |
| **证明 Proof** | 为什么是对的 | 纸面 + 拜恩配色逐步拼合，每步一句字幕 | 勾股定理拼图 | 开普勒第三定律推算 | 算法正确性、复杂度推导 |
| **证据 Evidence** | 怎么被证实的 | 真实数据 / 底片 + 观测 vs 理论面板 | 水星 574″−531″=43″ | 红移测距、引力波波形 | 测试通过、基准测试结果 |
| **数据 Data** | 规模与趋势 | 曲线 / 对比，点逐个亮，右侧结论 | 摩尔定律对数曲线 | 尺度阶梯（地球→星系） | 复杂度曲线、性能对比 |
| **旅程 Journey** | 在哪里、怎么传播 | 卫星地图 / 星图飞行 + 航线 | 丝绸之路、互联网扩散 | 旅行者号航线、光走的路 | 一个请求跨越的网络 |
| **展厅 Gallery** | 一组同类事物 | 3–6 张展品卡 / 博物馆长廊推镜 | 电气革命六件展品 | 太阳系行星卡片 | 编程语言 / 机器的演进卡片 |
| **第一视角 POV** | "我"亲手做 | 手入画 / 望远镜视野 / 眨眼 | 打石、看木星卫星 | 透过目镜、触碰星图 | 我敲下代码、按下运行 |
| **大字 Quote** | 一句话定调 | 压暗 0.88 + 宋体大字 + 出处 | "机器能思考吗？"（图灵 1950） | 天文学家的原话 | 程序员的经典原话 |

（大字引语必须核实原文和出处；网上流传的"名人名言"很多是误传或意译，查不到原始出处就不用。）
| **呼吸 Breath** | 情绪停顿 | 纯画面 2–3 s，无面板，环境声 | 发射、地出、1945 | 日食、星空 | 编译成功后的安静一刻 |

一段里通常：定场 → （人物）→ 实物 → 机制 / 证明 → 证据 / 数据 → 应用（实物或展厅）→ 呼吸 / 交棒。
这是检查清单，不是顺序模板；按内容增删，相邻镜头的类型尽量不同。

## 9. 分镜方法

1. **列节拍**：这一段要让观众明白的 3–5 件事，每件事写成一句"带数字的事实"。
2. **为每件事找主视觉**：先问"有没有真的东西可以看"；没有才用图解；再决定是机制、证明、证据还是数据。
3. **写分镜表**（项目 README）：

   | 时间 | 镜头类型 | 主视觉（素材键 / 组件） | L1 / 面板内容 | 字幕 | 转场（理由） | 声音 |
   |---|---|---|---|---|---|---|

4. **排节奏**：标出亮场 / 暗场、暖 / 冷、密集 / 呼吸，避免三连同类；每 60 秒一个呼吸镜头。
5. **自查**：每段都有真实视觉、原理或证明、数字、应用；Claude 在场；转场有理由；
   **和以往的片子比较**——如果某段的镜头组合和星火某章几乎一样，换掉它。
