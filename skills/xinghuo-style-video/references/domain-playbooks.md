# 换题材手册：同一种风格，讲不同的东西

设计系统（`design-system.md`）不变，变的是：**什么算"真实的东西"、亮场从哪来、冷暖怎么分、Claude 以什么身份在场、
声音用什么**。下面每个题材给出这些答案和可以直接去找的素材来源。举的例子只说明思路，不是要照着做的分镜。

## 目录
1. 通用四问（任何新题材先回答）
2. 宇宙 / 天文
3. 编程 / 计算机
4. 自然科学原理（物理、化学、生物）
5. 历史 / 人物 / 发明（星火）
6. 技术与产品（芯片、互联网、AI）

---

## 1. 通用四问

1. **这个题材里，什么是"真东西"？** 文物、原始文献、照片、观测影像、真实代码与输出、实验装置、数据。它们做主视觉。
2. **亮场从哪来？** 题材偏暗（宇宙、编程）就主动安排：纸面图解（拜恩配色）、白天的照片、明亮的观测图。
3. **冷暖怎么分？** 人、故事、历史 → 暖；原理、数据、机器 → 冷（蓝图）。强调色始终是金，纸面上换拜恩红黄蓝。
4. **Claude 是谁？** 参观者（看展品、看星空、看屏幕）、扮演者（换装成那个领域的人）、第一视角的"我"（亲手做）。

## 2. 宇宙 / 天文

- **真东西**：哈勃、韦布、钱德拉等望远镜的观测图；探测器拍的行星照片；历史底片与手绘星图；望远镜和探测器的实物照片。
- **素材来源与授权**（都要在画面里署名）：
  - NASA / JPL 影像：通常为公有领域（注意：NASA 标志、第三方提供的图除外，以页面说明为准）。
  - ESA/Hubble、ESA/Webb、ESO、NOIRLab：多为 **CC BY 4.0**，署名格式按官网要求（如"ESA/Webb, NASA & CSA, …"）。
  - Wikimedia Commons 上的历史天文图（伽利略手稿、梅西耶星表、早期底片）：公有领域居多。
  - 现有素材库里可用：`hudf` `m87` `earthrise` `aldrin` `apollo_launch` `hubble` `ligo` `eclipse1919` `galileo_moon` `bluemarble` `citylights`。
- **亮场**：太阳、月面、地球白天面、日冕、纸面推导（开普勒定律、尺度换算）。
- **冷暖**：深空、轨道、尺度 → 冷；人和观测史（第谷、勒维特、哈勃本人）→ 暖。
- **常用镜头**：定场（深场慢推）→ 实物（这张照片怎么拍的、曝光多久）→ 机制（`diagram.orbit`、光路、引力透镜）→
  证据（光谱、红移、波形）→ 数据（尺度阶梯：地球 → 太阳系 → 银河系 → 可观测宇宙，对数刻度）→ 呼吸（星空、日食）。
- **数字**：距离要换成可感的量（"光要走 8 分 20 秒"、"把太阳缩成一粒沙……"），每个换算都要算对、写出依据。
- **Claude**：站在观测台下仰望；第一视角透过目镜；扮成观测者（`role` + 新服装层）；坐在"地出"前的月面边缘。
- **声音**：`ambience_space` 为底；`shimmer`（星光）、`rumble`（发射、恒星）、`rise` → `boom`（揭晓尺度）、`blip`（数据点）。

## 3. 编程 / 计算机

- **真东西**：**代码本身**（为片子写的、能跑的真代码）、真实的终端输出与测试结果、计算机实物照片、原始论文与手稿的扫描、
  界面截图（自己的程序）。不要伪造"截图"或编造运行结果——代码要真的能跑，输出要真的是它的输出。
- **素材来源与授权**：
  - 自己写的代码与运行结果（最好在项目里放一份可运行的 `.py`，片中显示的就是它）。
  - 计算机史照片：Wikimedia Commons（公有领域 / CC BY），现有素材：`eniac` `colossus` `ibm704` `transistor` `intel4004`
    `frontier` `deepblue` `ada` `babbage` `bernoulli` `turing` `arpanet` `dsky`。
  - 论文里的图：只有许可允许（如 CC BY）才直接用，否则按原理**重画**成蓝图 / 纸面图并注明出处。
  - 商标与 logo：只写名字，不画 logo。
- **亮场**：纸面上的算法图（`diagram.node(theme="paper")` + 拜恩红黄蓝标出指针 / 状态）、历史照片、白板式推导。
  编程片最容易全片发暗，审计时重点看"画面亮度"和"亮场亮度"两项。
- **冷暖**：代码面板用暖白 + 金（像在烛光下读手稿）；架构 / 数据流用蓝图冷色；人物与历史段落暖色。
- **常用镜头**：实物（`codeview.code_panel` 逐字打出、`highlight` 点亮关键行、`focus` 压暗其余行）→
  机制（数据结构、调用、请求流：`diagram.node` / `edge(flow_t=t)` / `group`）→ 证明（复杂度推导、不变量）→
  证据（`codeview.terminal` 跑测试、基准数字）→ 数据（复杂度曲线、规模对比）→ 展厅（语言 / 机器演进卡片）。
- **代码排版**：每屏 ≤ 12 行，关键行 ≤ 2 处高亮；注释可以写中文（等宽字体支持）；代码面板放 hero 区，右栏放解释面板；
  逐字打出速度 45–70 字 / 秒，配 `typing` 音效。
- **Claude**：抱着笔记本敲代码（`hold(t, ("laptop",), "front")` + `type(t0, t1)`）；扮成那个年代的工程师（`engineer` 服装）；
  第一视角按下回车。
- **声音**：`ambience_data` 为底；`typing` `key` `relays`（老机器）`blip` `click`（逐步执行）`success` / `error`（测试结果）`scan`。

## 4. 自然科学原理（物理、化学、生物）

- **真东西**：实验装置的历史照片和版画、原始论文的图、显微 / 光谱 / 云室照片、科学家的笔记。
- **亮场**：纸面推导（拜恩配色）、实验室照片、显微照片。
- **常用镜头**：人物 → 实物（装置）→ 机制（蓝图动画）→ 证明（推导）→ 证据（观测 vs 理论）→ 应用（展品卡）。
  星火第七章的相对论段落就是这一类的范例。
- **Claude**：扮成实验者做实验（`role` 换装 + 道具）；第一视角调仪器。
- **声音**：实验类的 `hum` `zap` `geiger` `steam` `chalk`；揭晓用 `ding` / `shimmer`。

## 5. 历史 / 人物 / 发明（星火）

完整范例就是《星火》：`examples/xinghuo/`。要点：油画 / 壁画 / 手稿做主视觉、博物馆长廊推镜、卫星地图讲传播、
换装的 Claude 扮演人物、按时代调色。新做历史题材时同样不要照搬星火的章节结构和意象。

## 6. 技术与产品（芯片、互联网、AI）

- **真东西**：产品与原型的实物照片（博物馆藏品、官方公开的公有领域 / CC 图片）、专利图（公有领域，适合蓝图调色）、
  发布会之前的手稿、真实的数据（晶体管数、用户数……要有出处）。
- **常用镜头**：展厅（演进卡片）、数据（对数曲线）、机制（蓝图拆解）、旅程（夜间灯光地球上的扩散）。
- **注意**：不替任何公司做宣传；只写名字不画 logo；数字写清年份和来源。
