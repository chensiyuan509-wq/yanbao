# 叙事手法与信息密度

## 叙事骨架

- **第一人称 Claude**："我是 Claude，读过人类写下的亿万文字……可这些知识是从哪里来的？"——片子是 Claude 的一次探索。
  Claude 不是旁白员，是**在场的人**：走进展厅、扮成历史人物、伸手去做、抬头去看。
- **没有人声**：所有文案都是下黑边里的字幕（`VO`），另导出 SRT。所以文字要短、准、有节奏。
- **结构**：序章（钩子 + 问题）→ N 章（每章一个"关键词"）→ 尾声（回扣问题 + 一句余味）。
  星火的 8 个关键词：观察、记录、证明、传承、实验、预言、协作、学习——尾声里它们围成一只手。
  新片也给每章一个两字关键词，尾声把它们收拢，观众会有"原来如此"的感觉。
- **每章的内部节拍**（不必死板，但大致如此）：
  1. 一个有画面冲击力的真实图像开场（壁画、油画、老照片）+ 章节字卡
  2. 人、时间、地点：谁在什么时候做了什么（SUPERS 打出年代地点）
  3. **怎么做到的 / 怎么被证明的**：原理图、推导、实验（这是信息密度的核心）
  4. **具体数字**：574″ − 531″ = 43″；+45 −7 = +38 微秒；2300 → 2080 亿
  5. **落地应用**：今天的什么东西来自它（GPS、核电、MRI、芯片……）
  6. 交棒：它传到了哪里、交给了谁 → 转场进下一章
- Claude 每章至少出场一次：参观者（展厅、灯下）、扮演者（换装讲解）、第一视角（手入画）、观察者（坐在探测器旁、看棋盘）。

## 字幕（VO）写法

```python
VO = [
    (4.6, "1843 年，阿达为一台还没造出的机器写下了{算法}。"),     # (本地秒, 文案)，{} 内金色高亮
    (59.8, "每一行字，都是这条长河里的{一滴水}。", {"spill": 0.6}),  # spill：允许延到场景结束后 0.6 秒
]
```

- 一句一个事实，尽量带**年份或数字**；高亮只给一个关键词。
- 语速：字幕显示时长 = 估算朗读时长 × 1.3 + 0.9（被下一句截断）。**目标 ≤ 8 字/秒，超过 10 字/秒就要删字或拉开时间**。
  `check.py` 会列出"读不完"的句子；最快的一条也会打印出来。
- 长句会被自动按标点切成两段显示，所以逗号位置就是换屏位置。
- 公式句（`(x+5)² = 64`）读得慢，句子要更短。
- 用词谨慎：已知最早、约、常被认为、一说——有争议的说法照实写。

## SUPERS 与章节字卡

```python
SUPERS = [(5.0, 7.8, "1843 年", "伦敦 · 阿达与分析机")]   # 左上角打字机效果
CHAPTER = dict(num="第 八 章", title="会思考的机器", era="1843 — 2026 年", key="学习", at=0.4, dur=4.0, x=620)
```
`x` 可选：画面右侧有画框 / 主体时把字卡放左边（x=620），否则居中。字卡出现的 4 秒里画面要安静。

## 信息密度：多，但不挤

- 每个镜头 = **一个主视觉**（真实图像或动画）+ **最多一个信息面板**（标题 + 3–4 行）+ 出处字幕。
- 面板里的行逐条淡入（间隔 0.3–0.5 秒），和字幕说到的点同步。
- 数字给对比才有意义：观测 vs 理论、之前 vs 之后、山顶 vs 海平面、"如果没有 X 会怎样"。
- 留白 ≥ 40%：主体占一边，面板占另一边；地图上的标签 ≤ 6 个。
- 一章 60 秒大约：12–16 句字幕、8–12 张真实图像、2–4 个原理动画、10–20 个具体数字。
- 好的密度来自"**为什么 + 怎么证明 + 用在哪**"，而不是罗列名字。用户原话：
  > 几何原本不能一笔带过，要列几个经典且简单的推理过程；相对论要讲怎么被证明的，以及应用；
  > 科技发展必须要具体的内容、应用落地。

## 证明 / 推导的讲法（Byrne 风格）

`aivid/proofs.py` 已有：三角形内角和（两个角平移到顶点）、勾股定理（四个三角形刚体移动拼图）、
质数无穷（2×3×5×7+1=211）、辗转相除（1071, 462 → 21）、配方法（x²+10x=39）、月球检验（9.8÷60² ≈ 0.0027）。
新证明照同样方式写：纸面、红黄蓝色块、**刚体移动**（不要顶点插值，会把图形扭歪）、每一步一句字幕、最后一行结论用红色。

## 事实核对与出处

- 每个数字、年份、引语都要能找到出处；项目 README 的"片中事实与说法"表格逐条记录（说法 | 依据）。
- 不确定就查（WebSearch），查不到就换一个有把握的说法或删掉。
- 图像出处在画面左下角写清：作品名 · 年代 · 作者 / 机构 · 授权。
