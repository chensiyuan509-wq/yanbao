# 视觉风格手册（星火风格）

一句话：**真实的历史图像打底 + 电影级的光与运动 + 克制的信息面板 + 一个会探索、会扮演的 Claude**。
既要有"博物馆 / 纪录片"的厚重感，又要有"蓝图 / 数据"的科技感；两种质感按时代切换，不混成一锅。

## 1. 画布与安全区

- 设计坐标固定 **1920×1080**，渲染时缩放到 480p / 720p / 1080p。所有坐标都按 1920×1080 写。
- **2.2:1 遮幅**：上下黑边各 `LB = 96`，有效画面 y ∈ [96, 984]。字幕画在下黑边里，不压画面。
- 胶片质感三件套：颗粒（每个场景 `GRAIN = 0.07`）、暗角（`film.vignette(ctx, 0.4–0.6)`）、遮幅。
- 固定位置（别和它们抢地盘）：
  | 元素 | 位置 |
  |---|---|
  | 档案出处字幕 `caption()` | 左下，x=118，y≈900，标题 36 号 + 小字出处 |
  | 年代 / 地点字幕 `SUPERS` | 左上，x=118，y=160，打字机效果 |
  | 章节字卡 `CHAPTER` | 默认画面中央 y=500；画面右侧有主体时用 `x=620` 放左边 |
  | 信息面板 `panel()` | 右三分之一：x≈1150–1840，y≈170–720 |
  | Claude | 地面带，脚底 y≈905–960；避开左下出处字幕区 |

## 2. 颜色

| 用途 | 色值 |
|---|---|
| 正文主色（暖白） | `#F6EEDF`、`#F2E6CE`、`#F4ECDF` |
| 金色强调 / 面板标题 / 年份 | `#D9B26A`；高亮数字 `#FFD27A`；光 `#FFE2B0` `#FFC46B` |
| 次要文字 | `#CFC4B0`、`#BFAE8E`、`#9A8C78`（出处小字） |
| 警示 / 反例 | `#FF8A6A`、`#FF9A7A` |
| 蓝图底 | `#123056 → #06101F` 径向；网格线 `#7FC8FF`（0.08 / 0.14） |
| 蓝图文字 / 线 | `#E8F2FF` 主、`#BFE0FF` 次、`#7FD8FF` 光线 / 波形 |
| 面板底 | `#0E0C10` × 0.78，描边强调色 × 0.45，圆角 16 |
| 展厅墙 | `#1A1512 → #2A221C`，石纹 0.12，顶灯光锥 `#FFE2B0` 0.22 |
| 拜恩（Byrne）几何 | 红 / 黄 / 蓝三原色 + 黑线，纸面底（`proofs.paper`） |
| 暗场背景 | 径向 `#1C202A → #05060A`（科技）、`#24120A → #020101`（火光） |

规则：一个画面里强调色最多两种（金 + 一种）。数字用金色，反例用橘红，其余都是暖白。

## 3. 字体与字号

字体别名在 `aivid/core.py` 的 `FONTS`：

| 别名 | 用途 |
|---|---|
| `serif_k`（思源宋体 Black） | 章节标题、片名、大数字、面板里的关键词 |
| `serif_sb`（SemiBold） | 面板正文、说明牌、标签 |
| `serif_r` / `serif_m` / `serif_l` | 小字出处、副标题、片尾 |
| `medium`（思源黑体） | 只用于下黑边的字幕 |
| `latin` / `latin_b` / `latin_i` | 西文、拉丁文书名、型号（GP100、ENIAC） |
| `eq`（DejaVu Serif） | 公式：∇ ∂ ₀ ≈ − × ÷ ″ ² 都有；**中文不要放进 eq**，拆成两段 |
| `kai` | 甲骨、竹简、书法感 |
| `cune` `hiero` `brahmi` `deva` `phoen` `linb` `arabic` `sym` | 古文字 / 符号 |

字号（设计坐标）：章节标题 118；片名 170–200；面板标题 30；面板正文 26–30；大数字 38–84；
出处小字 20–22（最小）；卡片：年份 30 / 名称 46 / 两行说明 29。480p 下 22 号约等于 10 像素，再小就看不清。

字形坑：`″ ′ ✓ ≈ −` 在宋体 / 西文里可能是方块 → 用 `eq` 字体或直接画（打勾就画两条线）。
`check.py` 会查字幕和画面文字的缺字。

## 4. 时代调色

| 时代 | 质感 | 调色 / 光 |
|---|---|---|
| 史前 | 洞穴、火光、石器 | 暖橙火光，`film.embers`，`lit("#FFB070")`，壁画 `grade="warm"` |
| 古文明 | 泥板、纸草、壁画、卫星地图 | 暖褐，卫星图 `tone="warm"`，`film.grade("#FFB070", 0.08)` |
| 古典 / 中世纪 | 湿壁画、手稿、拜恩几何 | 原色或 `sepia`，纸面纹理 |
| 科学革命 | 油画肖像、版画、手绘 | 原色油画 + 烛光暗角 |
| 工业 | 浪漫主义油画、版画剖面 | 炉火暖色 + **蓝图**（`grade="blueprint"` 把线描版画变成蓝图） |
| 电气 / 20 世纪 | 老照片、专利图、展品 | 老照片 `mono`，原理图蓝图，夜间灯光地球 |
| 太空 / 计算 | NASA 影像、机房照片 | 深蓝黑底，冷光，数据面板 |
| 尾声 | 星图、篝火 | 回到暖色，渐黑 |

`archive.show(..., grade=...)` 可选：`mono` `sepia` `warm` `cool` `cool_mono` `fire` `dim` `blueprint`。

## 5. 十三种构图

每种都在 `examples/xinghuo/scenes/` 里有能直接抄的实现。

1. **档案推拉 + 右侧面板**：全屏 Ken Burns（`arch()`），左下出处，右侧 `panel` 3–4 行要点。最常用。
   例：s07 `_s9a`（索尔维会议）、s08 `_f1`（IBM 704 + 达特茅斯）。
2. **左图右文**：肖像占左 58%（`kb(..., rect=(0,0,W*0.58,H))`），右侧黑底列表。例：s07 `_s2` 爱因斯坦 1905。
3. **博物馆长廊推镜**：Claude 走过挂着真实画作的展厅，镜头推进画框直到画心铺满，**硬切**接同一张图的 `kb`
   （起始裁切 `(0.5, 0.5, 1.02)`），观众感觉"走进了画里"。例：s03 `_shot_a0`、s08 `_a`。
4. **展品卡片一排**：3–6 张 `card()`（上半真实器物照片，下半年份 / 名称 / 两行原理或应用），轮流高亮；
   超过 4 张就横移。例：s06 `_f`（电气革命六件展品）、s08 `_d`。
5. **蓝图原理图**：`blueprint_bg` + 动画（光点沿光路走、活塞动、仪器转）+ 编号步骤面板。
   例：s06 `_b`（蒸汽机剖面）、s07 `_s3b`（迈克耳孙干涉仪）。
6. **卫星地图飞行**：`oldmap.draw_satellite` + `MapCam` 关键帧 + `city_sat` / `route` / 弧线。
   古代用白天暖色，现代用夜间灯光。例：s02 `_shot_a`（四大河）、s08 `_f3`（互联网从 CERN 扩散）。
7. **暗墙聚光的画框**：`framed()` + 顶灯光锥 + Claude 站在下面看。例：s07 `_s1`（灯一盏盏亮起）。
8. **灯箱 / 实物特写 + 示意图**：真实底片放在发光灯箱上，右侧画原理示意。例：s07 `_s6b`（1919 日食）。
9. **拜恩几何证明**：纸面 + 红黄蓝色块，一步步移动拼合，扮成欧几里得的 Claude 在右下角讲。例：s03 `_shot_b`、`aivid/proofs.py`。
10. **数据曲线压在调暗的照片上**：对数坐标、点逐个亮、右侧结论面板。例：s08 `_e`（摩尔定律压在 4004 版图上）。
11. **第一视角**：`film.pov_arm`（Claude 的手伸进画面）、`film.eyelids`（睁眼 / 眨眼）、`film.scope_view`（望远镜）。
    例：s01 打石、s05 看木星卫星、s09 触碰星座。
12. **记忆漂浮**：真实图像缩略图在暗空间里漂浮、向主角汇聚（文字微粒流进身体）。例：s08 `_i`、序章模板。
13. **大字引语**：画面压暗到 0.88，宋体大字逐渐拉开字距 + 一行出处。例：s08 `_c`（"机器能思考吗？"）。

## 6. 不要做的事

- 不要火柴人、剪影小人代替角色——人物要么是**真实的历史肖像 / 照片**，要么是**换装的 Claude**。
- 不要手绘感的地图——用卫星影像 + Natural Earth 矢量。
- 不要伪造"历史图像"：没有可用授权的真图，就画示意图并注明"示意"，别拿 AI 生成图冒充文物。
- 不要把字压在人脸 / 画面主体上；面板放右侧空处，压不开就换裁切。
- 不要一屏塞两个面板 + 一堆标签；一屏一个重点。
- 不要 PPT 式的翻页、飞入、旋转。
- 不要静止超过 2 秒的画面——至少缓慢推拉。
