# 看见时间 · Claude 的宇宙时间课

用代码生成的 3 分钟科普动画：以 Claude 小人的视角，把抽象的"时间"讲给没有物理基础的人听。

- 成品：`out/claude_time.mp4`（1920×1080，30fps，3:00，H.264 + AAC）
- 中文字幕：已烧录在画面里；另附 `out/subtitles.srt`（可导入剪辑软件或播放器）
- 所有画面、角色、配乐、音效都由代码实时绘制或合成，不依赖任何外部图片或音频素材
- Claude 小人按 `assets/image.jpg` 的造型和 11 种表情（neutral / happy / curious / think / surprised / determined / tired / sleep / yawn / proud / excited）用矢量重绘，能眨眼、走路、挥手、跳跃、挤压拉伸

## 分镜

| 时间 | 章节 | 讲什么 | 怎么把它画出来 |
|---|---|---|---|
| 0:00–0:12 | 开场 | 时间无处不在，却看不见 | Claude 走上小星球，四周浮现半透明的"幽灵时钟"；标题逐字浮现 |
| 0:12–0:30 | 一 · 什么是时间 | 没有变化就没有先后；时间是给变化排顺序的尺子 | 整个世界"冻结"成灰蓝色，两张一模一样的"之前/之后"照片；解冻后颜色涌回，蜡烛变短、叶子飘落、Claude 打哈欠，事件依次落到一把"时间尺子"上 |
| 0:30–0:51 | 宇宙日历 | 138 亿年压缩成一年 | 大爆炸→时间长河；变成 12 个月的日历，镜头逐级推进：12 月 → 12 月 31 日 23:48（人类出现）→ 最后一分钟（文字历史 = 最后 12 秒，你的一生 ≈ 0.2 秒） |
| 0:51–1:03 | 时间之箭 | 熵增让时间有方向 | 杯子摔碎；"倒放"时碎片飞回去被打上红叉；盒子里两种颜色的粒子从有序混成一团，熵条上涨；过去→未来的大箭头 |
| 1:03–1:20 | 二 · 怎么感知时间 | 测量时间 = 数重复 | 镜头横移三个工位：钟摆（每秒 1 次）→ 石英（32,768 次）→ 铯原子（9,192,631,770 次），计数器实时滚动 |
| 1:20–1:40 | 心理时间与光的延迟 | 感受不准；看到的都是过去 | 分屏：开心时表针狂转、无聊时几乎不动；镜头从 Claude 拉远到月亮、太阳、北极星、仙女座星系，光子沿光线飞向眼睛，标出"多久以前"；星星变成"宇宙相册"里的老照片 |
| 1:40–1:58 | 三 · 时间与空间 | 时空、世界线、光速限速 | 每个瞬间是一张照片，照片一张张叠成"时空块"，Claude 的位置连成世界线；镜头旋转到侧面，变成时空图，出现 45° 光锥和"超光速：不可能" |
| 1:58–2:18 | 光钟与双生子 | 运动让时间变慢 | 静止光钟 vs 高速光钟：光走斜线、路更长，嘀嗒次数肉眼可见地拉开；双胞胎以 0.87 倍光速往返，地球 10 年、飞船 5 年 |
| 2:18–2:35 | 四 · 质量扭曲时间 | 质量弯曲时空；GPS 要做相对论修正 | 3D 网格"橡皮膜"，地球落下压出一个坑，坑里的钟走得慢、远处的钟走得快；GPS 卫星每天快 38 微秒（+45 −7），地图上的定位点一天漂出约 10 公里 |
| 2:35–2:45 | 黑洞 | 视界附近时间几乎停止 | Claude 坠向黑洞：身体越来越红、越来越暗，眨眼和挥手越来越慢，最终定格；远处的钟照常走 |
| 2:45–3:00 | 结尾 | 时间会伸缩、会弯曲 | 日出、波动的时空织网；屏幕上的计时器显示观众刚刚度过的真实时长；片尾"看见时间" |

转场：圆形展开（iris）、柔边擦除（wipe）、推拉缩放（zoom）、横推（push）、白闪（flash）、淡入淡出；场景内还有推镜、拉镜、横移、旋转等运镜。

## 运行

依赖：Python 3.9+、pycairo、numpy、imageio-ffmpeg（自带 ffmpeg），以及中文字体 Noto Sans CJK SC（Ubuntu/Debian：`sudo apt install fonts-noto-cjk`）。

```bash
# pycairo 用系统包最省事：sudo apt install python3-cairo
python3 -m venv venv --system-site-packages
source venv/bin/activate
pip install -r requirements.txt     # 如果系统没有 pycairo，这一步也会装它（需要 libcairo2-dev）

python render.py                     # 完整渲染 → out/claude_time.mp4（8 核约 4–6 分钟）
python render.py --scale 0.5         # 960×540 快速预览
python render.py --still 25 90 160   # 只导出这几秒的画面到 out/stills/
python render.py --start 100 --end 118 --out out/part.mp4   # 只渲染一段
```

## 目录

```
render.py          渲染入口：多进程逐帧绘制 → ffmpeg 分段编码 → 拼接 → 混入音轨
tv/core.py         引擎：缓动函数、关键帧、颜色滤镜（冻结去色 / 引力红移）、文字、图形、镜头
tv/claude.py       Claude 小人：11 种表情、走路、挥手、眨眼、跳跃、挤压拉伸
tv/props.py        道具：星空、时钟、蜡烛、树、地球、月亮、卫星、火箭、黑洞、原子、钟摆……
tv/scenes_a.py     开场、什么是时间、宇宙日历、时间之箭
tv/scenes_b.py     测量时间、感知时间（心理时间 / 光的延迟）、时空
tv/scenes_c.py     光钟与双生子、质量与 GPS、黑洞、结尾
tv/scenes.py       场景时间表与转场表
tv/timeline.py     字幕脚本、章节卡、进度条、SRT 导出
tv/audio.py        用 numpy 合成配乐（和弦铺底 + 铃声琶音）与全部音效
assets/image.jpg   角色表情参考素材
```

改字幕：编辑 `tv/timeline.py` 里的 `SUBS`，`{花括号}` 内的文字会高亮。改场景时长：同时调整 `tv/scenes.py` 的 `SCENES` 与对应场景里的关键帧时间。
