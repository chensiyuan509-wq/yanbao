# 阶段 04：雪夜上梁山 → 落草受气 → 火并王伦 → 让位晁盖（第十回–第十九回，idx 0011–0020）

## 阶段小结
- 处境与目标：杀人放火的通缉犯（“出三千貫信賞錢捉拿正犯林沖” L288）；目标从“安分服刑”变成“找个安身处”。
- 对手与关系：王伦（嫉贤妒能的寨主）；朱贵（引路）；杨志（对手→惺惺相惜）；吴用（暗中激将）；晁盖（他亲手扶上第一把交椅）；曹正（徒弟，侧面）。
- 结果：投名状受辱 → 王伦为制衡杨志才勉强留他坐第四位 → 晁盖七人上山，林冲火并王伦，拒坐首位，扶晁盖为主，自己仍坐第四位；得知妻子自缢、丈人病故。
- 心态：从“有家難奔，有國難投”的悲凉 → 被王伦一再羞辱的憋屈 → 第二次爆发（这次为“义气”） → 让位、潸然泪下、“杜絕了心中掛念”。
